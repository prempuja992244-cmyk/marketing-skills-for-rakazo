# Marketing analytics report

## Metrics that matter (per channel)
- **YouTube**: views, viewed-vs-swiped (Shorts), average view duration/% viewed, click-through rate, subscribers gained, returning viewers.
- **Instagram**: reach (followers vs non-followers), plays, average watch time, shares/sends, saves, profile visits, follows, link taps.
- **Facebook**: reach, 3-second/1-minute video views, shares, comments, Group activity.
- **LinkedIn**: impressions, comments, reposts, follower growth, profile views, newsletter subscribers.
- **Email**: delivered, open/click trend, replies, unsubscribes, spam complaints.
- **Website/SEO**: Search Console clicks/impressions, top queries, conversions.
- **GBP**: calls, directions, website clicks, reviews.
- **Business**: leads, sales, cost = ₹0 ads; attribution via UTM (`mkt-utm-tracking`).

## Report format
1. Headline numbers vs last period (↑/↓).
2. Top 3 and bottom 3 pieces of content with likely reasons (hook, topic, format, time).
3. 3 insights.
4. 3 actions for next week (double down, fix, test — `mkt-experiments`).

## Automation
Pull via connected integrations or exports; write to a sheet; send the summary to the user every Monday.

## Rules
Compare like with like (same period length); don't over-read small numbers; follower count is not the goal — leads and sales are.
