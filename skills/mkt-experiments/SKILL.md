# Experiments

## Backlog and prioritisation (ICE)
List ideas; score Impact, Confidence, Ease (1–10 each); run the highest average first.

## Test design
- **Hypothesis**: "If we open Reels with the finished result instead of the process, 3-second hold will rise because viewers see the payoff."
- **One variable** only (hook / thumbnail / length / time / format / CTA / subject line).
- **Metric** chosen in advance (e.g. viewed-vs-swiped, shares per reach, CTR, sign-up rate).
- **Sample**: at least several posts per variant or enough views/sends to see a clear gap; note small samples as directional.
- **Duration**: fixed window (e.g. 2 weeks).

## Tools
Platform features: YouTube thumbnail/title tests, Instagram trial reels, email A/B splits, landing page variants.

## Record
Experiment | hypothesis | variants | metric | result | decision (adopt / drop / retest) | learning. Keep `experiments.md` as the team's playbook.

## Rhythm
1–2 experiments running at all times; review monthly.
