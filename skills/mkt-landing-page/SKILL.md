# Landing pages and conversion

## Structure (single goal)
1. **Headline**: outcome for the specific visitor + subhead on how.
2. **Hero**: product/result image or short video; primary CTA button.
3. **Problem → solution** in 3 bullets.
4. **Proof**: testimonials, numbers, logos, reviews, before/after.
5. **How it works**: 3 steps.
6. **Offer details**: what's included, price or free, guarantee.
7. **FAQ**: top objections.
8. **Final CTA** repeated.

## Link-in-bio page
Lead magnet first, then best offer, booking/WhatsApp, latest video; ≤ 6 links; UTM per link (`mkt-utm-tracking`).

## Conversion checklist
Mobile-first, loads fast, one main CTA, form fields minimal, message match with the post/ad that sent traffic, trust (address, contact, policies), no distracting navigation.

## Improve
Check analytics (visits → sign-ups/sales); run one change at a time (`mkt-experiments`): headline, hero, CTA text, proof placement.

## Build
Draft copy and sections; publish via the connected site builder after approval, or deliver an HTML page.
