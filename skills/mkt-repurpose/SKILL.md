# Repurpose one idea into 10–20 pieces

## Input
A long-form source (video URL/transcript, blog, recording) or a strong post.

## Steps
1. **Get the transcript/text** (YouTube captions through the connected YouTube app, or the user's file).
2. **Extract**: 5–10 standalone moments (a tip, story, stat, strong opinion, mistake, question answered). Each must make sense alone.
3. **Map to formats**:
   | Source moment | Output |
   |---|---|
   | 30–45s clip with a clear hook | Short + Reel + Facebook Reel (separately exported, no watermarks) |
   | List of tips | Carousel (IG/LinkedIn) + X thread + Pin |
   | Story | LinkedIn story post + Threads post |
   | Full topic | Blog article (`mkt-blog-article`) + newsletter (`mkt-newsletter`) |
   | Local/offer angle | Google Business Profile post + WhatsApp channel update |
4. **Rewrite natively** for each platform (tone, length, format) — never paste the same caption everywhere.
5. **Schedule** across 2–3 weeks (`mkt-scheduler`) so the same idea isn't everywhere on one day.

## Output
A repurposing table: piece | platform | hook | caption | asset needed | date — plus drafts for each.

## Rules
Facebook and Instagram favour original content; upload native files and add your own edit or commentary rather than reposting other people's work.
