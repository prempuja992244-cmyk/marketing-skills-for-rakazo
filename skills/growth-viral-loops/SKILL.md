# Growth loops

Loops beat one-off campaigns: output of one cycle becomes input of the next.

## Loop types
1. **Invite/referral loop**: customer gets value → invites friends with a reason (shared benefit) → friends join → repeat.
2. **UGC loop**: customer creates content (review, result photo, unboxing) → others see it and buy → they create content.
3. **Content/SEO loop**: answer a question → page ranks/gets cited → visitors subscribe → their questions create new content.
4. **Collaboration loop**: collab with creator → their audience follows → bigger audience attracts better collaborators.
5. **Community loop**: members help members → answers become public resources → attract new members.

## Design steps
1. Choose the loop that matches the product's natural sharing moment.
2. Map each step and its conversion rate.
3. Remove friction at the weakest step (one-tap share, ready-made caption, QR, reward).
4. Estimate: if each new customer brings k others (k = invites × acceptance), k > 1 means self-sustaining; most loops are < 1 but still lower acquisition cost.
5. Instrument tracking (`mkt-utm-tracking`) and improve one step per experiment.

## Output
Loop diagram (text), step conversion estimates, friction fixes, experiments list.
