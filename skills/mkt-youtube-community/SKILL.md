# YouTube comments and community

## Daily comment routine (automatable)
1. Pull new comments via the connected YouTube integration (comment threads list).
2. Classify: question / praise / feedback / idea / complaint / spam / abuse.
3. Draft replies: answer questions specifically, thank with a personal touch, ask a follow-up question to continue the conversation.
4. Flag complaints and sensitive comments to the user (`mkt-approvals-safety`).
5. Hide/report spam per channel rules (only with approval for anything beyond obvious spam).
6. Add good questions to `audience.md` as future video ideas.

## Pinned comment
Ask a question that invites replies or point to the next video/lead magnet.

## Community posts (if available on the channel)
Polls to choose next topics, behind-the-scenes photos, quick tips, upcoming video teasers — 1–3 per week.

## Lives / Premieres
Use Premieres for big videos and go live for Q&A; announce 24h before across channels.

## Rules
Never buy comments or use fake accounts. Replies are drafts until approved, unless the user approved auto-replies for simple thank-you/FAQ replies.
