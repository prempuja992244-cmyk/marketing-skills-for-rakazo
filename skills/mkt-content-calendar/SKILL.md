# Content calendar

## Inputs
`brand-context.md`, `content-strategy.md` (pillars, cadence), `audience.md` ideas, upcoming dates (festivals, sales, launches, industry events).

## Build
1. Block key dates first: launches, offers, festivals relevant to the audience (e.g. Diwali, Eid, Christmas, New Year, exam season, wedding season), awareness days.
2. Rotate pillars so no pillar repeats more than twice in a row; keep ~1 in 5 posts promotional.
3. Assign each idea a **hero format** and plan its repurposed versions (`mkt-repurpose`).
4. Pick times from the account's own analytics; if none, start with the audience's local evening and lunch hours and test.

## Calendar columns
Date | Time | Platform | Pillar | Format (Reel/Short/Carousel/Text/Long video/Email/Story/GBP post) | Topic | Hook | CTA | Asset status (idea/script/shot/edited/ready) | Caption link | Approval | Published URL | Results (24h/7d).

## Save
Write to a connected Google Sheet / Notion / Airtable if available; otherwise `calendar-{month}.csv` and a readable table in chat.

## Batch workflow
Monday: plan week · Tuesday: write scripts and captions · Wednesday: record/design · Thursday: edit and schedule (`mkt-scheduler`) · daily: engage (`mkt-auto-engagement`).
