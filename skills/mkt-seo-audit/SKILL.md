# Website SEO audit

## Technical (check with browser + Search Console if connected)
- Site indexed? (`site:domain.com`), Search Console coverage errors, sitemap submitted, robots.txt not blocking.
- HTTPS, mobile friendly, Core Web Vitals / PageSpeed Insights.
- Important content visible without heavy client-side rendering (AI crawlers and search need HTML).
- Duplicate pages, broken links, redirect chains, missing canonical tags.

## On-page (top 10 pages)
Unique title and meta description, one H1, keyword-topic match, helpful content depth, images with alt text, internal links, clear CTA, structured data (LocalBusiness, Product, FAQ, Article).

## Content
Pages per keyword cluster (`keywords.md`)? Thin or outdated pages to update/merge? Missing pages for high-intent topics (pricing, comparisons, locations, FAQs)?

## Authority
Google Business Profile complete (`mkt-local-seo`), mentions/links from local and industry sites (`mkt-digital-pr`).

## Output
Score table (OK / fix), top 10 quick wins ordered by impact ÷ effort, and drafted fixes (titles, metas, page outlines). Apply site changes only with approval.
