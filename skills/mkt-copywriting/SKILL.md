# Copywriting

## Pick a framework
- **PAS**: Problem → Agitate → Solution (pain-driven posts, offers).
- **AIDA**: Attention → Interest → Desire → Action (launch posts, landing pages).
- **BAB**: Before → After → Bridge (transformations, testimonials).
- **4Ps**: Promise → Picture → Proof → Push (sales pages, emails).
- **Feature → Benefit → Meaning** for product descriptions.

## Rules of clear copy
- One reader, one message, one action.
- Specific beats general: numbers, names, timeframes, places.
- Write how the customer talks (`audience.md` quotes).
- Short sentences, short paragraphs, line breaks for mobile.
- Benefits first, features as proof.
- Proof near every claim (testimonial, result, demo).
- Remove filler: very, really, just, innovative, world-class.

## Platform length guide
Instagram caption: hook line then value; LinkedIn: 1,200–2,000 characters story posts do well; Facebook: short with a question; X: one idea; product description: 50–150 words + bullets.

## Deliverables
2–3 variants with different angles, each with hook, body, CTA; note which persona each targets.

## Rules
No false scarcity, fake reviews, or unprovable claims. Follow health/finance claim rules; add required disclaimers.
