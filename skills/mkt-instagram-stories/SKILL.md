# Stories that engage and sell

Stories mostly reach existing followers, so they build relationship and conversions.

## Daily rhythm (3–7 frames)
1. **Hello/context**: what's happening today (real, casual).
2. **Value**: tip, behind-the-scenes, process.
3. **Interaction**: poll / quiz / question / emoji slider.
4. **Proof**: customer message screenshot (with permission, private info hidden), review, result.
5. **Action** (2–3 times a week): link sticker, "DM me WORD", offer.

## Story sequences
- **Launch** (3 days): problem → teaser → reveal → FAQ → reviews → last call.
- **Q&A Friday**: collect questions with the question sticker, answer in the next frames.
- **Day in the life**, **new arrivals**, **before/after**.

## Highlights
Save evergreen frames to highlights: Start here, Reviews, Products/Prices, FAQ, How to order.

## Automation
Draft the day's frames (text + image brief) each morning in `mkt-daily-routine`; the user records quick clips; schedule via an integration if it supports stories, else remind the user.
