# Short video script (Shorts / Reels)

## Length
Default 20–45 seconds. Go longer only if every second earns its place; completion and rewatches matter. Instagram notes that for reaching new people, staying under 3 minutes is safer.

## Script template
```
TITLE / IDEA:
HOOK (0–2s): spoken line + on-screen text + opening visual
SETUP (2–6s): why this matters to the viewer
VALUE (6–35s): 3 quick beats / steps / reveals, one idea per cut
PAYOFF: the result or the answer promised in the hook
CTA (last 2–3s): one action — follow for part 2 / comment "WORD" / save this / link in bio
ON-SCREEN TEXT: per beat (max ~6 words)
B-ROLL / SHOTS: per beat
CAPTION: 1–3 lines + 3–5 relevant keywords/hashtags
AUDIO: original voice, or trending audio from the platform library
```

## Formats that work without big budgets
Talking head with captions · screen recording tutorial · before/after · day-in-the-life / behind the scenes · myth vs fact · listicle with fast cuts · customer reaction/testimonial · green-screen commentary on a trend · faceless hands + voiceover.

## Production checklist
Vertical 9:16, good light (window), clear audio (phone mic close), burned-in captions, cut every 1–3 seconds, no watermarks from other apps (re-export clean files per platform).

## Rules
Use only music from platform libraries or royalty-free sources. Disclose paid partnerships. Label realistic AI-generated content where the platform requires it.
