# Email newsletter

## Format (keep it consistent)
- **Subject**: specific benefit or curiosity, ≤ 50 characters; preview text adds detail (`mkt-hooks`).
- **Opening**: 1–3 lines, personal and direct.
- **Main value**: one tip/story/insight with an example.
- **Extras**: 2–3 quick links (your new video, a useful resource).
- **CTA**: one main action (reply, watch, book, buy).
- **Sign-off**: real name; P.S. line for the offer.

## Content mix
80% value (tips, stories, behind the scenes, answers to subscriber questions), 20% offers. Ask readers to reply — replies help deliverability and give content ideas.

## Schedule
Same day and time each week (or fortnight). Plain-text style often feels more personal and lands better.

## Sending
- Small personal lists: Gmail drafts reviewed by the user.
- Lists of any size for marketing: a connected email service that handles one-click unsubscribe and bounce handling (`mkt-email-deliverability`).

## Automation
Weekly routine: collect the week's best content → draft newsletter → send test to the user → schedule after approval → report opens/clicks/replies/unsubscribes next week.
