# Growth model: North Star + AARRR

## 1. North Star metric
The one number that best captures value delivered to customers and predicts revenue (e.g. weekly repeat orders, active paying members, bookings completed). Add 2–3 input metrics the team can move.

## 2. Map the funnel with real numbers
| Stage | Question | Example metric |
|---|---|---|
| Acquisition | How do people find us? | visitors/followers/leads by source |
| Activation | Do they get the first "aha"? | sign-up → first use/order % |
| Retention | Do they come back? | repeat purchase / 30-day active % |
| Referral | Do they bring others? | referral rate, invites per user |
| Revenue | Do they pay more over time? | conversion %, AOV, LTV |

## 3. Find the constraint
Compare each stage to a sensible benchmark for the business type and to last month. Fix the biggest leak before pouring in more traffic (more traffic into a leaky bucket wastes effort).

## 4. Plan
Pick 1 stage for the next 30 days → generate 10 ideas (`growth-hacks-library`) → score with ICE → run experiments (`mkt-experiments`) → weekly review.

## Output
`growth-model.md`: North Star, inputs, funnel table with numbers, constraint, 30-day plan.
