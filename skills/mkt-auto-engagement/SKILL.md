# Engagement routine

Replying quickly to comments (ideally in the first hour after posting) keeps conversations going, which platforms reward.

## Daily (1–3 times)
1. **Collect** new comments, mentions, DMs and reviews from connected platforms.
2. **Classify**: question, praise, lead/buying intent, complaint, spam/abuse, collaboration request.
3. **Draft replies** in brand voice — specific, human, often ending with a question. Vary wording.
4. **Leads** → reply + send to sales follow-up (or `mkt-dm-automation` flow); log in the sheet/CRM.
5. **Complaints / sensitive** → hand to the user (`mkt-approvals-safety`).
6. **Spam** → hide/delete per policy (obvious spam only unless approved).
7. **Outbound**: list 10 niche posts/creators to engage with today and draft thoughtful comments for the user to post or approve.

## Approval
Default: one batch for approval. Auto-reply allowed only for categories the user approved (e.g. thank-you replies, FAQ answers).

## Never
Buy engagement, use engagement pods, follow/unfollow tactics, generic bot comments ("Nice post!"), or auto-DM people who didn't engage first.
