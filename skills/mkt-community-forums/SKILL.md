# Reddit, Quora and forums

These communities are also sources that AI search tools often cite, so helpful answers can help both direct traffic and AI visibility.

## Find threads
Search the niche keywords + "reddit"/"quora", subreddit search, Quora topics; prioritise recent questions with traction and old ones ranking on Google.

## Answer recipe
1. Answer the exact question in the first 2 lines.
2. Add specifics: steps, numbers, examples, personal experience.
3. Format with short paragraphs or bullets.
4. Mention your product only if relevant and allowed, with disclosure ("I run a bakery supplies shop, so I'm biased, but…").
5. Link only when it truly adds value and the community permits it.

## Profile
Real name or brand, short bio with what you do; on Reddit build genuine history before mentioning your business.

## Rules
Read and follow each subreddit/forum's rules; no vote manipulation, alt accounts, copy-paste answers, or astroturfing. The bot finds threads and drafts answers; the user posts or approves.
