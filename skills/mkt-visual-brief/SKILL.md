# Visual brief and design

## Brand kit (set once, save in `brand-context.md`)
2 brand colours + 1 accent, 2 fonts (headline/body), logo files, photo style (bright/natural/dark), do/don't examples.

## Common sizes
- Instagram feed 1080×1350 (4:5); Story/Reel cover 1080×1920 (9:16)
- YouTube thumbnail 1280×720; channel banner 2560×1440 (safe area 1546×423)
- Facebook post 1080×1350 or 1080×1080; Page cover ~1640×624 (check current spec)
- LinkedIn post 1200×1200 or 1080×1350; banner 1584×396
- Pinterest 1000×1500 (2:3)
- X post 1600×900

## Brief template
Purpose · platform/size · headline text (≤ 6 words) · supporting text · main visual (photo/product/face/icon) · layout (focal point, text placement) · colours · CTA · reference examples.

## Production
If Canva or a design tool is connected, create from the brand template. Otherwise produce a clean image with the bot's tools or give the user a ready Canva-style spec. Export per platform size; add alt text.

## Rules
Use own photos, licensed stock, or generated images; never copy logos/characters of other brands; real faces only with permission.
