# Funnel and journey audit

## Mystery-shop (bot does it on its computer, as a customer would)
1. Find the brand on Google/Maps, Instagram, YouTube — what's the first impression?
2. Profile → link → landing page → form/checkout/WhatsApp → confirmation → follow-up.
3. Time each step; note confusion, slow pages, missing info (price, delivery, location), broken links, slow replies.
(Do not submit real orders or payments; stop before any payment step.)

## Data check
Analytics drop-offs per step, form completion rate, cart abandonment, reply time to enquiries, show-up rate for bookings.

## Friction list
Each issue: step | problem | evidence | impact (H/M/L) | effort | fix.

## Typical quick wins
Price/FAQ visible, WhatsApp click-to-chat, fewer form fields, faster first reply (auto-acknowledge), reviews near CTA, clear delivery/return policy, follow-up within 24h for enquiries.

## Output
Journey map, prioritised fix list, and drafted copy/messages for the top 5 fixes.
