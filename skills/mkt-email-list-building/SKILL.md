# Email list building (opt-in only)

An email list is an owned channel — no algorithm decides who sees it.

## Opt-in points
- Lead magnet (`mkt-lead-magnet`) linked from every bio and pinned post.
- Website: header link, inline form in blog posts, exit-intent pop-up, footer.
- YouTube: description link + spoken CTA; pinned comment.
- Comment-to-DM flows that deliver the magnet (`mkt-dm-automation`).
- In-store / events: QR code to the form.
- Checkout/booking: consent checkbox (unticked by default).

## Form setup
Ask only for email (and first name). Say what they'll get and how often. Use double opt-in where possible. Store consent source and date.

## Tools
Connected email service (Mailchimp, Brevo, ConvertKit/Kit, Beehiiv, etc.) or Google Sheets + Gmail for very small lists. Plain Gmail is fine for personal 1:1 emails but not for large bulk newsletters — use a proper sender with unsubscribe handling (`mkt-email-deliverability`).

## Hygiene
Remove bounces; re-engage then remove subscribers inactive for ~6 months; never buy or scrape lists.

## Output
Opt-in map for the brand, form copy, thank-you page copy, and welcome email trigger (`mkt-email-sequences`).
