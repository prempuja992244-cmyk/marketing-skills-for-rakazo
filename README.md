# Marketing Skills for Rakazo

**A marketing, growth hacking and business development plugin made only for Rakazo — organic, zero ad spend, built for hands-free automation.**

76 skills + 5 slash commands. Instructions only — no scripts, no MCP server, no secrets. Researched against platform guidance and 2026 industry reporting (YouTube, Instagram, Facebook, LinkedIn, X, Threads, Pinterest algorithms; Gmail/Yahoo sender rules; local SEO and AI search).

## Install in Rakazo
1. In Rakazo open **Integrations → + → From GitHub**.
2. Paste `https://github.com/prempuja992244-cmyk/marketing-skills-for-rakazo` and choose **Preview**.
3. Check the preview lists the skills and commands, then choose **Add**.
4. Open a bot and type `/mkt-setup`.

Installs are pinned to a commit: after the repository changes, remove the plugin and add it again.

## Commands
| Command | What it does |
|---|---|
| `/mkt-setup` | Brand, audience, strategy, account connections, routines |
| `/mkt-today` | Today's results, replies, posts, trend idea, recording script — one approval batch |
| `/mkt-plan-week` | Plans and drafts next week across all platforms |
| `/mkt-repurpose-this <link or text>` | One piece → 10–20 platform-native posts, scheduled |
| `/growth-audit` | Finds the growth bottleneck and builds a 30-day experiment plan |

Or just talk to the bot — `mkt-assistant` routes any request.

## Hands-free without sharing passwords
Connect Gmail, YouTube, Instagram, Facebook Pages, LinkedIn, X, Pinterest, Google Business Profile, Search Console, Sheets and your email tool in Rakazo **Integrations** (official sign-in once). For anything without an integration, log in once on the bot's computer using **Protected input**. The bot never asks for or stores passwords and never bypasses login checks or CAPTCHAs.

## Safety defaults
Organic only — no bought followers, likes, reviews, engagement pods or spam bots. Drafts first: publishing, replies, DMs, emails and profile changes need your approval unless you explicitly auto-approve a category (e.g. daily tip Shorts, thank-you replies).
